HOW TO PLAY / НИКАКОЙ ПОДГОТОВКИ

Твоя первая фраза — за три шага

  1. PRESS RЗапись начнётся сразу. START нажимать не нужно.
  2. PLAY NOTESA–L — мелодия. Для ритма выбери Loop 2 и играй Z X C V.
  3. PRESS R AGAINФраза сохранится сразу. Повтор начнётся с ближайшего такта.

После первого лупа выделится пустой Loop 2. Нажми R, сыграй ритм и снова нажми R. Затем играй поверх обоих лупов.

OFF сохраняет твой ритм без округления. Auto выбирает 1, 2 или 4 такта (~2.31 / 4.62 / 9.23 секунды при 104 BPM). Можно выбрать длину заранее. QUEUED означает: фраза уже готова, повтор ждёт ближайшего такта. Пока он ждёт, можно записывать второй слой.

Restore возвращает твою сохранённую репетицию без запуска звука. Space запускает её. Start Fresh открывает пустые дорожки. Сохранение работает только в этом браузере.
