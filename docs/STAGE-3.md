# Stage 3 — Interactive Practice Mode

Локальный инструмент: `http://127.0.0.1:8767/`.
Папка: `/Users/matveyabramov/Documents/GitHub/ringtone-machine-prototype`.

## Как начать

Обнови страницу и нажми **Учиться** → **Начать**. При первом открытии есть также кнопка **Учиться пошагово** в HOW TO PLAY. Нужна английская физическая раскладка клавиш A–L / Z–V (обработчик использует физические позиции, поэтому подписи соответствуют латинской клавиатуре).

1. **Мелодия:** A → D → F → D. Сначала без спешки нажми и отпусти каждую подсвеченную клавишу. Затем сыграй после четырёх щелчков. Начала: 0 / 1.25 / 2.50 / 3.75 с; удержания 0.35–0.50 с. «Следующий урок» открывает запись: **1 → R → фраза → R**. После R сразу начинай первую ноту, затем следуй шкале. Auto или 2 bars; OFF удобнее для точной проверки.
2. **Ритм:** C → X → C → X (CLICK / PING). Те же три этапа, но пэды не нужно долго держать. Запись: **2 → R → фраза → R**. Урок засчитывается после двух реально начавшихся циклов Loop 2 при одновременно работающем Loop 1. Если слой заглушён, верни его Q/W. QUEUED означает, что данные уже сохранены и ждут общей границы такта.
3. **Управление:** записать новый дубль, убрать/вернуть мелодию Q, ритм W, поднять/опустить SIGNAL [ / ], остановить/запустить Space, сыграть поверх обоих лупов и закончить Esc. Каждое задание включается кнопкой «Начать» или при переходе «Следующий урок» и ждёт фактического действия.
4. **NO ANSWER:** семь сцен с текущим и следующим действием. Урок начинает новый сюжет на пустых учебных дорожках: очисти их Start Fresh двумя нажатиями. Сохранённое исполнение из «Играть» это не затрагивает.

**Повторить** начинает текущее упражнение заново, сохраняя учебные лупы. Для нового дубля нажми R самостоятельно. Во время записи сначала R — закончить, либо T — отменить; после этого доступны повтор и выбор урока. **Выйти / Играть** прекращает текущую тренировку и возвращает исходные партии и настройки. Выйти можно и посреди записи: отменяется только учебный дубль.

## Обратная связь

Оценка использует реальное время `Tone.immediate()` — AudioContext без lookahead. Учебный отсчёт и эталонные позиции находятся на той же шкале. Движение линии рисуется по этому времени; CSS и интервальные таймеры не определяют музыкальную точность.

По умолчанию начало считается точным в пределах **±200 мс**. Ползунок задаёт **±50–400 мс** для следующей попытки. Во время оценки он заблокирован. Удержание мелодической ноты оценивается отдельно: 350–500 мс. Естественный хвост Release синтезатора не включается в длительность удержания. Для пэдов оценивается однократное нажатие, а не gate.

Неверная клавиша не расходует ожидаемую ноту, но отмечается как лишнее/неверное нажатие; пропущенная остаётся видна в результате. Ранние и поздние нажатия показывают отклонение в миллисекундах. Для прохождения ритмической попытки нужны четыре правильные ноты с верным временем, для Voice A — также удержанием, без лишних нажатий. В режиме поиска клавиш ошибки можно исправлять без таймера.

На этапе **Запиши фразу** оценка дополнительно проверяет настоящие сохранённые events: число, высоты/пэды, порядок, два такта, позиции и длительности относительно исходных физических нажатий. Учебный модуль не подправляет запись. Сетка OFF сохраняет исходную игру; при явно включённой сетке допускается только её предусмотренный сдвиг onset, длительность остаётся исходной. Finish при ещё удерживаемой ноте ждёт её реального отпускания для оценки; автоматический cleanup не засчитывается как удачное отпускание.

После сохранения проверяется реальный вызов инструмента из Transport и достижение его аудиовремени: одного факта R недостаточно. Успех не означает, что программа умеет слышать динамики: это проверка аудиорасписания и состояния, дополненная независимыми PCM-тестами.

## Репетиция NO ANSWER

| Сцена | Что действительно выполнить | Ориентир |
|---|---|---:|
| Завязка | Одиночные Z и X, оставляя тишину | 20 с |
| Первый поворот | Записать A D F D в Loop 1, услышать запуск | 25 с |
| Развитие | Записать C X C X в Loop 2 поверх первого | 25 с |
| Центральная точка | 6 отпущенных живых нот, 3 разные клавиши, оба слоя играют | 25 с |
| Второй поворот | Реально увеличить SIGNAL до ≥70% | 20 с |
| Кульминация | Убрать и вернуть оба слоя, затем 8 живых звуков, включая ≥2 ноты и ≥2 пэда | 25 с |
| Развязка | По порядку убрать Loop 1, затем Loop 2; финальная нота ≥0.4 с, отпускание и Esc | 20 с |

Итого **2:40**. Часы показывают время сцены и всей репетиции, но не блокируют ранний переход. После реального выполнения действия открывается следующая сцена; исполнитель сам решает, сколько развивать её. В сюжетном уроке ритм мотивов свободный. Готовая композиция, автоматические музыкальные партии и скрытая генерация нот отсутствуют. Автоматический звук — только четыре тихих учебных щелчка в ритмической практике.

## Устройство и сохранность

- `practice-core.js`: чистая оценка исходных событий и валидация сохранённого лупа.
- `practice.js`: отдельное состояние уроков, подсказки и чтение реальных событий инструмента. Нет вызовов Record, Mute, Select, SIGNAL или вставки score от имени пользователя.
- `app.js`: небольшой observer bridge (`input`, `record`, `commit`, `loop`, `mute`, `signal`, `transport`), управление временной сессией. `input` передаёт фактические note-on/note-off и причину отпускания; auto-repeat по-прежнему отсекает основной input handler.
- `loop-engine.js`, `audio.js`, `timeline.js`, Tone.js и WAV-файлы не изменены. На обе среды используется тот же действующий движок и аудиограф.
- При входе исходное исполнение ставится на Stop, events/settings копируются в память; тренировка получает пустые временные дорожки. Отложенное сохранение исходного исполнения сначала завершается, если оно было запланировано.
- Запись/очистка учебных лупов не пишет в localStorage. Исходное сохранение остаётся побайтно тем же. Restore в тренировке отключён. При выходе возвращаются events, длины, mute, выбранная дорожка, сетка, SIGNAL и состояние транспорта. Если исходное исполнение играло, оно возобновляется обычным Start **с начала лупов**, без восстановления прежней фазы.
- Метроном — отдельный тихий Tone.Synth, существующий только во время ритмического задания. Выход/повтор/смена урока/Esc удаляют его вместе с запланированными атаками. Он не использует Transport callbacks. Подсветка/cleanup не создаёт фиктивные note-on/note-off для оценки.

## Проверки

Проверки выполнялись в отдельном Chrome с локальным настоящим Tone.js 15.1.22 и изолированным browser storage. Основные сценарии используют настоящие keyboard/pointer events и production state machine, без создания тестовых музыкальных массивов в инструменте.

- `tests/practice.test.cjs`: 30 проверок оценщика — границы допуска, ранние/поздние, короткие/длинные, пропуски, лишние, неправильные клавиши, held/cleanup, проверка сохранённых onset/gate/grid/двух слоёв.
- `tests/practice-browser.test.cjs`: 55 E2E-проверок всех четырёх уроков: реальные две записи, два повторения второго слоя, каждая команда управления, семь сцен, неправильный порядок финала, ошибки ритма, выход при удержании/отсчёте, изоляция сохранения и возвращение Performance.
- `tests/practice-edges.test.cjs`: **21** дополнительных проверок действительного PCM отсчёта/тишины после выхода, запрета ложного успеха для неверной записи, отсутствующих слоёв, позднего отпускания после конца упражнения, настройки допуска, Space на кнопке, laptop/mobile layout, многократного удаления cue/аудиоузлов, Restore.
- `tests/fidelity-browser.test.cjs`: **109** регрессионных проверок исходного recording/playback pipeline. Для A A D F | G F D A: input 8 → raw 8 → saved 8 → scheduled 8 → timeline 8, Auto 2 bars. Максимальное расхождение относительных интервалов в реальном PCM: **7.1 мс** для ровной игры и **1.6 мс** для выразительной; расписание отличается от captured input максимум на **0.1 мс**. Также проверены cold start, held Finish, границы, два слоя, Mute/Restart/Restore и явные сетки.
- `tests/audio-regression.test.cjs`: **81** real-audio проверка аудиографа и waveform: полифония, отдельные голоса, duration 150/300/500/1000/1500 мс при всех сетках, Release, SIGNAL, один CALL attack, PING/CLICK/NOISE, ограничение уровня и отсутствие feedback.
- Исходные unit suites: fidelity 14 + recorder/session 30 + duration 23 = **67**.

Всего **363 успешных проверки**, включая 106 новых проверки Practice. После двух равных серий отмены учебного отсчёта число видимых браузеру native audio nodes: 148 → 148 (допуск на отложенное освобождение — 12); новых Transport callbacks нет.

Детальные результаты и снимки — в `docs/practice-validation/`. В аудиозаписи отсчёта измерено 4 атаки с интервалом **625 мс**. При измерении отсчёта сначала дождались Release последней вручную сыгранной ноты: её хвост не считался пятым щелчком.

Для повторного запуска без новых зависимостей укажи `PLAYWRIGHT_MODULE` на уже установленный Playwright и `PROTOTYPE_URL` на свой локальный сервер. Например:

```sh
node tests/practice.test.cjs
PLAYWRIGHT_MODULE=/path/to/playwright PROTOTYPE_URL=http://127.0.0.1:8767 node tests/practice-browser.test.cjs
PLAYWRIGHT_MODULE=/path/to/playwright PROTOTYPE_URL=http://127.0.0.1:8767 node tests/practice-edges.test.cjs
```

## Что проверить руками

1. На MacBook нажать Учиться → Начать; с ошибкой нажать S, затем пройти A D F D. Подсветка должна ждать отпускания и не спешить.
2. После четырёх щелчков сыграть мотив. Слишком быстро отпустить одну ноту и увидеть «слишком коротко»; повторить с удержаниями около 0.4 с.
3. Записать обе фразы через реальные R → игра → R. Услышать тот же рисунок в двух слоях, затем поиграть сверху и пройти управление.
4. В NO ANSWER не спешить: оставить тишину в завязке, развить импровизацию, поднять SIGNAL, вернуть слои и осознанно закончить. Ориентироваться на 2:40.
5. Выйти в «Играть»: исходные партии должны вернуться. Оценить комфортную громкость метронома и читаемость на своём экране. Задержка Bluetooth-наушников не компенсируется; для точности лучше встроенный звук или проводные наушники.

## Ограничения

- Прогресс уроков и учебные лупы временные: при выходе/обновлении они удаляются. Сохранённое исполнение Performance остаётся доступным через Restore.
- Вход в Practice во время активного дубля запрещён: сначала R или T. Выход отменяет учебный дубль. Возвращение ранее игравшего Performance происходит с начала лупов.
- Тренажёр проверяет события и аудиорасписание, не использует микрофон и не определяет аппаратную задержку динамиков/наушников. Результаты измерены в Chrome; Safari и физическую клавиатуру MacBook нужно проверить вручную.
- Точные уроки намеренно требуют все четыре верные ноты без лишних; допуск времени можно увеличить. При записи держи Auto/2 bars и начинай сразу после R. В сюжетной репетиции допускается свободный ритм.
- Guided Performance предлагает длительности, но не заставляет ждать: быстрое учебное прохождение может быть короче двух минут. В обычном режиме никаких метрономов, готовых партий и учебных звуков нет.
