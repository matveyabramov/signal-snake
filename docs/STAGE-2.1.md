# Stage 2.1 — Note duration & CALL fix

30 октября 2026. Локально, без публикации, commit или push.

## Причины

**Длительности:** Stage 2 независимо округлял onset и note-off, дополнительно растягивая минимальный gate до одного шага сетки. При 96 BPM это 625 / 312.5 / 156.25 ms для 1/4 / 1/8 / 1/16, поэтому удержание 150 ms могло стать 312.5 ms. Также note-off обрезался по длине цикла.

Целевой тест с реальными клавишами выявил второй сдвиг: сразу после Start Live PolySynth получал время `Tone.now()` (с lookahead 25 ms), а recorder — тики от `Tone.immediate()`. Пока транспорт ещё ожидал старта, onset записывался как ноль, а note-off уже отсчитывался от будущего старта. В измерении gate 144 ms сохранялся как 119 ms. Отдельное квантование скрывало такой сдвиг за более крупным шагом сетки.

**CALL:** причина в самом WAV. Он содержал две предусмотренные при генерации пачки 660/880 Hz: 0–270 ms и 400–680 ms. В диапазоне 300–380 ms — точная цифровая тишина. Значит, речь о двух отдельных атаках, а не о двух локальных максимумах обычного звукового колебания. Обработчики клавиатуры и Sampler не создавали второй ручной trigger; в тракте нет feedback delay.

## Исправление длительностей

- Note-on и note-off recorder получают **тот же запланированный аудиотаймстамп**, который передаётся живому Tone.js. Для событий используется Transport.getTicksAtTime(audioTime), для положения курсора — фактическое время воспроизведения. Это устраняет сдвиг на старте, сохраняя единый Transport.
- В исходном дубле сохраняются дробные down/up ticks. Gate = фактический up − down. Для ноты, ещё удерживаемой при FINISH/лимите, up берётся из момента закрытия записи.
- Квантуется только onset. Длительность не округляется. Playback off = quantized onset + original gate. У технического нулевого gate есть защитный минимум 1 ms; это не музыкальная сетка.
- Auto выбирает минимальную длину 1/2/4 по **сдвинутому onset плюс неизменённому gate**. Поэтому сдвиг onset вперёд возле границы может увеличить Auto с одного такта до двух вместо обрезания удержания.
- В фиксированном лупе, а также у предельного четырёхтактового окна, хвост после сдвига onset может переходить через границу цикла. Он не укорачивается. Уже существующий bounded pool даёт каждой итерации отдельную огибающую, в том числе при совпадении высоты; следующий цикл не обрывает предыдущую ноту.
- При переходе ноты через край и при FINISH/лимите с удержанием появляется краткое явное сообщение. Ручная нота продолжает звучать до keyup. Это единственное уточнение UI; управление и компоновка Stage 2 сохранены.
- Быстрые повторения могут попасть на одинаковый квантованный onset, но каждое реальное нажатие сохраняет свой gate. Повтор keydown при удержании не порождает дополнительные события.
- ADSR не менялся: attack 6 ms, decay 140 ms, sustain 0.35, release 90 ms. Release — отдельное послезвучие после записанного gate.

## CALL

Заменён только `assets/audio/call.wav`: тот же mono PCM 44.1 kHz / 16 bit, те же 660/880 Hz и общая длительность 800 ms. Убрано включение второго burst; вместо него — одна плавная атака 8 ms и непрерывный экспоненциальный спад с коротким затуханием края. Это не искусственное укорочение до click.

PING, CLICK, NOISE, `audio.js`, HTML и CSS побайтно не менялись. Общая маршрутизация SIGNAL сохранена. Старый дефектный CALL хранится только как QA fixture `tests/fixtures/call-stage2-before.wav` и никогда не загружается игровым экраном.

## Сохранение

Новые сессии имеют version 2: положительные дробные duration в тиках и допустимые хвосты через конец цикла. Ключ localStorage оставлен прежним для совместимости. Version 1 читается и сохраняет старую музыку; потерянные при прежнем округлении note-off восстановить невозможно. Для точных длительностей старые фразы следует записать заново.

Ни Restore, ни обновление страницы не запускают музыку автоматически. Чужие/готовые партии не добавлены.

## Аудиоизмерения

Для каждого сочетания 1/4, 1/8, 1/16 × 150/500/1500 ms записанное событие рендерилось через production `playLoopNote`. Эталон — отдельный Tone.Synth с теми же параметрами, явными triggerAttack/triggerRelease заданной длительности и тем же выходным графом. Это независимый known-length gate, не повторное применение recorder/quantizer.

Для всех девяти сочетаний аудиосэмплы совпали с эталоном: относительная RMS-ошибка 0 в выполненном тесте. После gate + release звук возвращается к тишине. Тест не использует визуальную подсветку для измерения длительности.

Реальные браузерные нажатия проверялись отдельно; задержка самого тестового нажатия не считалась ошибкой recorder:

| --- | --- | --- | --- |
| 1/4 | 150 ms | 154.7 ms | 154.7 ms |
| 1/4 | 500 ms | 501.3 ms | 501.3 ms |
| 1/4 | 1500 ms | 1504.0 ms | 1504.0 ms |
| 1/8 | 150 ms | 154.7 ms | 154.7 ms |
| 1/8 | 500 ms | 506.7 ms | 506.7 ms |
| 1/8 | 1500 ms | 1504.0 ms | 1504.0 ms |
| 1/16 | 150 ms | 154.7 ms | 154.7 ms |
| 1/16 | 500 ms | 506.7 ms | 506.7 ms |
| 1/16 | 1500 ms | 1498.7 ms | 1498.7 ms |

Тесты CALL считают раздельные активные области огибающей RMS (окно 20 ms, шаг 10 ms, порог 8% максимума с гистерезисом), а не каждую вершину синусоиды. Учитывается реальная sampleRate декодированного браузером буфера.

- Исходный WAV: 2 атаки, между ними тишина. Исправленный: 1 атака.
- Реальный production render, SIGNAL 0 / 0.5 / 1: 1 атака, без повторного эха. Пики: 0.0909 / 0.0969 / 0.1607.
- Три записанных события CALL: ровно 3 атаки при SIGNAL 0 и 1.
- Доля RMS 400–500 ms относительно 40–90 ms: 0.094 — естественное затухание, не второй удар.
- Реальные Z + восемь лишних keydown/repeat: 1 ручной pad trigger, 1 Sampler attack, 1 записанное событие. Следующие три прохода лупа дали ровно три дополнительных Sampler attack.
- PING/CLICK/NOISE по-прежнему звучат и затихают. Пиковый уровень плотного микса после замены CALL — 0.3545, без накопления feedback.

## Что проверить на слух

1. Обновить вкладку, чтобы загрузились новые скрипты и WAV. Не восстанавливать старую фразу для оценки новых gate: записать её заново.
2. На сетках 1/4, 1/8, 1/16 сыграть короткую (~150 ms), среднюю (~500 ms) и длинную (~1500 ms) ноту. В повторе удержание должно сохраниться; примерно 90 ms Release остаётся естественным хвостом.
3. Нажать FINISH при удержании: запись ноты заканчивается на FINISH, ручной звук — только при отпускании. В фиксированном однотактовом лупе поздняя нота должна дозвучать через край без обрыва.
4. Одно Z без активного CALL-лупа: один отчётливый attack и затухание. Затем записать одно Z: один attack на каждом повторе. Проверить SIGNAL 0% и 100%.
5. Если играть Z одновременно с уже звучащим CALL-лупом, ручной и записанный слои намеренно складываются; это два действия, а не лишний trigger одного нажатия.

DUOTONE MINI и старая презентация не менялись. Новые музыкальные партии в приложение не добавлены.
