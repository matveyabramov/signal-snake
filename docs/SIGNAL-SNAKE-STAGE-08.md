Дата: 30 октября 2026 года. Подготовлен код релиза; публикация не выполнялась.

## Результат

`dist/` — 29 файлов, около 793 КиБ. Главный `index.html` создаётся из `snake.html`. Входят только рабочий UI, JS-движок, audio graph, Tone.js 15.1.22, CALL/PING/CLICK WAV, семь Nokia SVG, Pixel Ultima Bold / IBM Plex Mono / Onest, лицензии и уведомления, `.nojekyll`. В `dist/` нет старых страниц, Stage 3, Functional Core, документации разработки, тестов, карт, JSON-партитуры, диагностических страниц, MIDI, MP3 и PDF. Данные семи сцен, необходимые для исполнения и подсказок, включены в JS без изменения композиции.

Сборщик `tools/build-public.py` работает без установки зависимостей. Список публичных файлов явный; ссылки HTML/CSS проверяются по нему, пути относительные. Повторная сборка даёт те же байты и SHA-256. При неизвестных файлах, каталогах или symlink сборщик останавливается без удаления их содержимого.

`.github/workflows/pages.yml`: только `workflow_dispatch` и только ветка `main`, сборка и публикация `dist/` официальными Pages Actions. Автопубликации при push нет. Deployment environment — `github-pages`; полномочия `pages: write` и `id-token: write` ограничены job публикации.

Главный README переписан под финальный инструмент: концепция, два голоса, управление, семь сцен, технологии, локальный запуск, Figma и будущий Pages URL, порядок первой публикации. История старых этапов остаётся в документации.

## Целевой production QA

Проверялся только артефакт `dist/` на изолированном локальном сервере под `/signal-snake/`, без доступа к корню репозитория. Тест `tests/release-browser.test.cjs` использует реальный Chrome и поставляемый Tone.js; код приложения и DSP в сетевых ответах не подменяются. Тестовые наблюдатели записывают вызовы настоящего графа и анализируют PCM выхода.

Итог: **98 проверок пройдены**. Первый запуск остановился по таймауту ожидания третьей сцены; диагностический повтор полного целевого прохода с записью состояния прошёл все семь переходов. Таймаут не повторился, код движка не менялся. Стресс-тесты не запускались.

- Тишина до CONNECT. Первый CONNECT: pitch 0, signal 0, mute false, пустой ритм; реальный мелодический PCM без клиппинга, первый пик 0.03591, RMS короткого измеренного окна 0.00922. Ритмических событий при первом запуске нет. Это инструментальная проверка, а не прослушивание человеком; предыдущий подробный DSP-отчёт остаётся в `SIGNAL-SNAKE-CONNECT-AUDIO-FIX.md`.
- MELODY 4×8 и RHYTHM 3×8 редактируются; ритм вступает на следующей полной границе, LCD-сканер следует шагам. Mute работает мышью и Space. Оба голоса используют один транспорт и один scheduler.
- PING отправляет настоящий ручной сигнал; ВЫСОТА достигает движка; ПОМЕХИ и физическая кнопка СИГНАЛ синхронизированы с полосками связи. V не вызывает NOISE, запросов noise.wav нет.
- Каждая из семи строк выбирает сцену всей своей шириной. Все семь сцен реально вступили на границе цикла с исходной мелодией и сбросом ритма, pitch, signal и mute. Все 26 существующих подсказок помещаются при 1280×720.
- STOP, повторный CONNECT и Escape работают; LIVE отражает фактический транспорт. После STOP нет активного воспроизведения.
- Нет JavaScript/console errors, failed requests или HTTP-ошибок ресурсов страницы. Все 23 уникальных запроса страницы остаются в `/signal-snake/` (либо локальные blob URL Tone). Три рабочих шрифта загружены. WAV совпадают с исходными.
- Двенадцать прямых внутренних URL, включая прежний HTML, карты, тесты, docs, PDF, noise.wav и `.git/config`, вернули 404 через отдельные запросы теста; страница эти запросы не делает.
- Визуальная проверка снимков и геометрии: desktop 1512×900, 1512×800, 1440×800, 1366×768, 1280×720, 1920×1080 — все сцены и управление без прокрутки. Mobile 390×844 и 360×800 — без горизонтального переполнения, естественная вертикальная прокрутка; CONNECT и STOP доступны. Mobile проверен размером viewport Chrome; физические устройства и Safari/Firefox в этом проходе не проверялись.

Артефакты: `/private/tmp/signal-snake-stage08/interaction.json` и восемь PNG рядом. Итоговый запуск: `/private/tmp/signal-snake-stage08-run.txt`. После браузерного QA изменены только тексты лицензионных уведомлений; JS/CSS/HTML/WAV/SVG/шрифты артефакта сохранили проверенные хеши.
