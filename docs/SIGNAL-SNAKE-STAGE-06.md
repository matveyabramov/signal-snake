## Layout

- Внешняя сцена использует `100dvh` с fallback `100vh`. Минимальная высота 900 px удалена.
- Внутренний desktop-cockpit сохраняет геометрию макета и масштабируется единым CSS transform. Размер его внешней области соответствует фактическому масштабу; глобальный zoom и обрезание страницы не используются.
- Масштаб вычисляется из `window.innerWidth`, `window.innerHeight` и измеренной высоты содержимого, обновляется при resize, загрузке шрифтов и изменении размеров подсказок через ResizeObserver.
- Телефон сохраняет пропорции. Его положение и масштаб внутри исходного макета уточнены по обновлённому Figma; корпус, LCD, кнопки и семь существующих SVG сохранены.
- Активные области стрелок и слайдеров расширены без увеличения нарисованных значков и дорожек.
- Масштаб ограничен снизу 2/3. При экстремально низком окне страница нормально прокручивается.
- При ширине до 1050 px используется последовательная вертикальная компоновка. Мобильный телефон масштабируется по ширине; нижние цифровые клавиши остаются внутри корпуса.
- Сохранены дополнительные элементы Stage 5: mute, состояние отложенного ритма, исполнительские подсказки, ссылки на обе карты исполнения и резервную страницу.

## Типографика и подписи

В репозитории Pixel Ultima не было. Найден установленный `/Users/matveyabramov/Library/Fonts/pixel-ultima-bold.ttf`. В его metadata указаны Pixel Ultima / Bold / PixelUltima-Bold, автор Douglas Leão и SIL OFL 1.1. Из этого файла подготовлен полный WOFF2 без подмены семейства или начертания, добавлен текст лицензии. Новая загрузка шрифта из интернета не выполнялась.

`pixel-ultima-bold.woff2` применяется к NO ANSWER, SIGNAL SNAKE, названиям сцен и заголовку УПРАВЛЕНИЕ. Локальный IBM Plex Mono Regular также преобразован в WOFF2 и применяется к техническим подписям, значениям и русскоязычному тексту. Onest остаётся на брендовой надписи телефона и цифровой клавиатуре согласно макету.

Chrome DevTools Protocol подтвердил фактические custom fonts для отрисованных глифов: PixelUltima-Bold в латинском заголовке и русской сцене, IBMPlexMono-Regular в подписи ВЫСОТА и метаданных LCD. В проверенных элементах системных fallback-шрифтов нет. Проверены кириллица обоих регистров, латиница, цифры и пунктуация в исходных cmap. Математического минуса U+2212 у Pixel Ultima нет; числовые значения с этим знаком используют IBM Plex Mono, где он присутствует.

Русские названия сцен, фаз и основные подписи соответствуют новому Figma. Это только представление данных: музыкальные имена/id/пресеты в JSON не изменены. Нижние параметры: ВЫСОТА −2…+2 и ПОМЕХИ 0…100%.

## Физическая кнопка СИГНАЛ

Клик переключает 0 → 25 → 50 → 75 → 100 → 0%. Промежуточное значение переходит на следующий уровень вверх: 40 → 50%.

Кнопка отправляет `input` существующему слайдеру, который управляет общим состоянием и имеющимся `engine.setSignal`. Отдельного аудиоэффекта нет. Сохраняются существующие плавные изменения фильтров, wet, vibrato и компенсации уровня за 45 мс. Синхронно обновляются процент, слайдер, полоски LCD, статус и tooltip. Есть 160-мс pressed feedback, native Enter/Space и accessible label «Изменить помехи». Фокус остаётся на кнопке.

## NOISE

В актуальном банке только CALL / PING / CLICK, RHYTHM — 3×8. `assets/audio/noise.wav` и его demo-копия остаются удалёнными. V не воспроизводит сэмпл, запросов `noise.wav` нет. Все семь сцен валидируются с разрешёнными источниками. Историческая партитура содержит архивные NOISE-события; действующий normalizer отбрасывает их, миграция сохранённых сессий также удаляет четвёртый pad вместо переназначения на другой звук. В цепи ПОМЕХ нет генератора широкополосного шума, добавлять его не потребовалось.

## Ограничения

Проверено в Chrome; Safari и физические мобильные устройства отдельно не проверялись. На низких desktop-окнах второстепенные служебные подписи уменьшаются вместе с cockpit; музыкальные клетки и активные области регуляторов сохраняют проверенные размеры. При дробном масштабе возможна обычная браузерная интерполяция пиксельных контуров. Исходная механика хранения состояния, ручных переходов и длительность композиции сохранены. Commit, push и публикация не выполнялись.
