# SIGNAL SNAKE: первый CONNECT при ПОМЕХАХ 0%

Исправление от 30 октября 2026 года. Проверяется `snake.html`, локальный Tone.js 15.1.22, настоящий Chrome/Web Audio. Музыкальные данные, UI и уровень чистого сигнала не менялись.

## Найденная причина

В `audio.js:createGraph()` создаётся `Tone.Vibrato({ depth: 0, wet: 1, ... })`. В поставляемой версии Tone.js конструктор Vibrato присваивает `depth.value = 0`; этот setter ставит событие на `Tone.now()`, то есть с lookahead 100 мс. До него у внутреннего Gain AudioParam глубины значение по умолчанию **1**.

Первый `snake.js:prepare()` вызывал `engine.setSignal(0)`. Прежний `audio.js:signal()` сначала выполнял `cancelScheduledValues(Tone.immediate())`, удаляя ещё не исполненное событие конструктора, а затем `setRampPoint()`. После отмены Tone восстанавливал старт ramp из начального значения **1**, а не из требуемого **0**. В Chrome измерено: Tone уже сообщает `depth.value = 0`, но native AudioParam остаётся примерно **0.8819444** даже через 1–2 секунды. При `wet = 1` ненулевая глубина Vibrato обрабатывает всю мелодию.

Это подтверждено временной шкалой событий и записью PCM исходного пути CONNECT. При повторном управлении слайдером создаётся новая автоматизация уже существующего параметра; возвращение на 0 устанавливает его фактическую глубину в 0. Именно поэтому ручной round-trip исправлял звук. Условия, отбрасывающего числовой ноль, не найдено. `Tone.start()` уже правильно вызывался из пользовательского жеста до загрузки WAV. При смене сцены и `silence()` пересоздавались источники, а не общий блок эффектов.

Отдельно найдено: при настройке нового Engine вызов `setMuted()` запускал `paint()`, который мог заменить выбранные до CONNECT ПОМЕХИ значением Engine по умолчанию. Исправлено в том же пути инициализации.

## Изменения

- `audio.js:createGraph()` перед возвратом применяет `signal(options.signal ?? 0, 0)`: все управляемые DSP-параметры задаются сразу, без стартового ramp, до первой ноты. Формулы обработки едины с ручным управлением.
- `audio.js:signal()` поддерживает немедленную инициализацию; обычные изменения сохраняют ramp 45 мс. `cancelAndHoldAtTime()` удерживает значение **до** отмены автоматизации; быстрый повторный ввод не сбрасывает незавершённый ramp. Нечисловые значения игнорируются.
- `snake.js:prepare()` передаёт текущее значение в граф и публикует Engine после настройки, чтобы `paint()` не перетирал начальные значения.
- `snake-engine.js:connect()/disconnect()` повторно согласуют DSP с текущим `engine.signal`. DISCONNECT отменяет также ожидающий сброс эффектов на будущей границе сцены; уже наступившая граница сначала применяется к состоянию. Существующие сбросы сцен и физическая кнопка продолжают пользоваться общим обработчиком ПОМЕХ.

Нулевое состояние: highpass 25 Гц, lowpass 15500 Гц, distortion wet 0, vibrato depth 0, output gain 0.82. В performance-режиме коэффициент distortion остаётся 0.35, но его ветвь полностью выключена через wet 0. Vibrato wet 1 при depth 0 не модулирует высоту; прежняя постоянная задержка сохраняется. Защитные WaveShaper/limiter и исходная квадратная форма синтезатора сохранены: эталон — нормальное прежнее состояние после round-trip, а не синусоидальный сигнал.

## Регрессия

`tests/snake-connect-audio.test.cjs` использует реальный Chrome и поставляемый Tone.js. В тесте добавляется только доступ для чтения параметров; алгоритм DSP и контроллер не подменяются. AudioWorklet записывает PCM выхода. A — первый цикл после новой загрузки и CONNECT при 0%; B — такой же цикл после новой загрузки, CONNECT и 50% → 0%. Сравниваются одинаковые три ноты исходной сцены: C5, Bb4, G4, длительность 4.615385 с. Анализируется левый канал стереовыхода, включая все тихие кадры.

Допуски: разница RMS менее 0.15 дБ; сумма абсолютных разностей нормированных гармонических энергий менее 0.02 для каждой ноты; разница внеполосной энергии менее 0.005. Для каждой ноты применяется окно Hann 8192 отсчёта и полосы ±22 Гц вокруг гармоник. Это проверка эквивалентности двух квадратных музыкальных сигналов, а не измерение абсолютного THD синусоиды. Побитное совпадение между независимыми живыми контекстами не требуется.

Дополнительно проверяются native AudioParam после первого CONNECT, DISCONNECT/CONNECT, перезагрузки, смены сцены, отменённой в lookahead смены сцены, задания 50% до CONNECT и всех пяти состояний физической кнопки СИГНАЛ. Проверяются единственный граф/планировщик, затухание выхода, непрерывность параметров при прерывании ramp и PCM быстрых переключений относительно контрольного резкого переключения. Запускаются существующие `snake-audio.html` и `performance-audio.html` для частот, отмены атак, всех трёх WAV, mute, отпускания нот и очистки будущих событий.

Запуск с локальным HTTP-сервером:

```sh
PROTOTYPE_URL=http://127.0.0.1:8771 node tests/snake-connect-audio.test.cjs
```

При внешней установке Playwright указать `PLAYWRIGHT_MODULE=/absolute/path/to/playwright`. По умолчанию WAV, параметры и JSON сохраняются в `/private/tmp/signal-snake-connect-audio`; можно задать `RESULT_DIR`.

## Короткая проверка на слух

Автоматически анализировались PCM и параметры; звук человеком не прослушивался. В Chrome обновить `snake.html`, нажать СОЕДИНИТЬ при 0%, прослушать один цикл; установить 50%, вернуть 0%, сравнить следующий полный цикл. Затем ЗАВЕРШИТЬ → СОЕДИНИТЬ, сменить сцену после 50%, пройти СИГНАЛ до возврата к 0% и завершить во время ноты. Проверить одинаковый чистый тембр при 0%, отсутствие новых щелчков и полную тишину после завершения.
