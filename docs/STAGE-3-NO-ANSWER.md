# Stage 3 — сохранённая рабочая база NO ANSWER v3.1

Работа остановлена по просьбе пользователя перед переходом к SIGNAL SNAKE. Новые функции и дополнительные проверки не продолжаются.

Реализованы: импорт исходного v3.1 JSON (52 такта, 104 BPM), Songbook семи сцен, локальный MP3 Reference и Tone.js Playable Preview, свободный Learn, Rehearse 60/72/80/92/104 BPM, ручной Live Guide, прозрачный reference overlay Piano Roll. Музыка не импортируется в рабочие лупы. Live Guide не переключает сцены и не исполняет партии автоматически.

Переключатели: SONG / NO ANSWER — партитура и Listen; LEARN — последовательность клавиш без экзамена; REHEARSE — четыре щелчка и самостоятельная игра; LIVE GUIDE — ручные сцены. Стрелки ←/→ меняют сцену, ↑ повторяет подсказки сцены, Enter меняет шаг; R, Q/W, SIGNAL и Esc остаются ручными.

Темп по умолчанию104. Изменение темпа заблокировано при игре/записи. Сохранение v4 содержит BPM, старые v1–v3 восстанавливаются как96 BPM. Прежняя строгая practice.js больше не подключается; её файлы/тесты оставлены как история. Текущий контроллер — song.js.

## Проверки, которые завершились

- 40 composition/tempo/MIDI checks.
- 21 проверка полного двухминутного прослушивания: 170 мелодических и307 pad events, финальная A на206.5, без LAST_CALL. После увеличения предварительного буфера preview до1 секунды диагностический maxLateMs был0 в последнем полном прогоне.
- 60 браузерных проверок Songbook/Preview/Learn/Rehearse/ручного Guided Performance. Реальный MAIN_HOOK PCM: максимальное расхождение интервалов3.85 мс; записанные удержания при104 BPM:3.04 мс относительно аудиособытий клавиатуры.
- 15 проверок физического исключения Preview из demo: модуль, импорт, MP3 и listening UI отсутствуют; ручная игра сохраняется. Проверялся отдельный сервер с корнем build/demo.
- 109 регрессионных browser-проверок recording/playback при явно выбранных96 BPM;61 проверка Piano Roll с новой мягкой системой Learn.
- 14 fidelity +23 durations +30 loops +24 editor model unit checks.

## Незавершённое / ограничения

Общий нагрузочный сценарий song-reliability.test.cjs не завершён: в последней попытке один замер удержания на80 BPM вышел за строгий допуск12 мс. Причина не установлена; дальнейшее расследование остановлено пользователем. Это не отменяет перечисленные успешно завершённые сценарии при104 и96 BPM. Аудиотайминг браузера может отклоняться при нагрузке; новые длительные прогоны не выполнялись.

Не проверены вручную Safari, физический трекпад и задержка наушников. Полная MP3-аранжировка содержит бас/гармонию; Playable Preview использует только существующие два голоса, а Live Guide упрощает ритм до C/X. Длительность живого выступления ориентировочная: сцены переключает пользователь.

## Запуск

```sh
cd /Users/matveyabramov/Documents/GitHub/ringtone-machine-prototype
python3 -m http.server 8767 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8767/ . Если сервер уже запущен, достаточно обновить страницу.

Демо без Preview находится в build/demo. Пересборка: python3 tools/build-demo.py . Для отдельного сервера только финальных файлов:

```sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory build/demo
```

Адрес демо: http://127.0.0.1:8769/ . Это локальная сборка, публикация не выполнялась.
