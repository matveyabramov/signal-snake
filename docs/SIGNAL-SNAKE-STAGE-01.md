# SIGNAL SNAKE — Stage 01

Исторический отчёт. В Stage 02 минимальная страница сохранена на `/snake-core.html`; музыкальная основа общая, NOISE удалён. Результаты ниже относятся к приёмке Stage 01.

## Локальный запуск

Из корня `signal-snake`:

```sh
python3 -m http.server 8771 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8771/snake.html. Установка npm-зависимостей для приложения не нужна. Tone.js 15.1.22, IBM Plex Mono и три WAV находятся в `assets/`; сетевые CDN не используются. Нужен HTTP-сервер, а не `file://`.

## Управление

- CONNECT запускает текущий рисунок с первого столбца. При первом подключении это `H H J G | H F G —`: `C5 C5 Eb5 Bb4 | C5 G4 Bb4 —`.
- Один столбец — четверть при 104 BPM (576.923 мс). Цикл — восемь четвертей, 4.615 с.
- MELODY: сверху вниз E♭5, C5, B♭4, G4. Нажатие устанавливает или заменяет ноту; повторное нажатие убирает её. Ноль или одна нота в столбце.
- RHYTHM: CALL, PING, CLICK (обновлено в Stage 02: NOISE удалён). Любая комбинация в столбце, начальная сетка пустая.
- Переключение сетки меняет только отображение. Оба голоса звучат одновременно.
- MUTE RHYTHM убирает ритмический слой и его хвосты; UNMUTE возвращает будущие события без повторной атаки текущего шага.
- SIGNAL 0–100% управляет существующими фильтрами, distortion и vibrato обоих голосов.
- DISCONNECT / Escape отменяет будущие атаки, освобождает звучащие голоса и сбрасывает сканер. Рисунки и настройки сохраняются в памяти до перезагрузки.
- Скрытие страницы останавливает звук; автоматического возобновления нет.

## Новая архитектура

- `snake.html` / `snake.css`: минимальная отдельная страница с сеткой и управлением.
- `snake-engine.js`: модель двух голосов и один callback на каждую четверть через существующий `Tone.getTransport()`. Отдельного таймерного транспорта нет.
- `snake.js`: DOM, загрузка аудио по явному жесту, защита асинхронного CONNECT поколением запроса, остановка при навигации и скрытии страницы.
- `audio.js`: `scheduleLoopNote()` возвращает отменяемый handle из существующего пула. `schedulePad()` даёт отдельный отменяемый one-shot; закончившиеся samplers освобождаются. `silence()` и `dispose()` очищают новые события тоже. Старый `playLoopNote()` сохраняет булевый результат и прежнее поведение.

Сетка читается при каждом callback с точным переданным аудиовременем. Пока шаг находится впереди фактического времени аудиочасов, правка отменяет только его прежнюю атаку нужного голоса и планирует новую на том же времени. Второй голос и транспорт не затрагиваются. Уже начавшаяся нота сохраняет свой конечный gate (72% четверти плюс исходный release); правка действует на следующий круг. Последние 5 мс перед атакой считаются уже принятыми Web Audio, поэтому такая пограничная правка тоже применяется на следующем круге. Визуальный сканер обновляется через Tone.Draw и защищён от callback предыдущего запуска.

Изоляция реализована отдельными документами: на странице Snake не загружаются Recorder, Songbook или Preview; на странице Stage 3 нет Snake-контроллера. При переходе старый документ останавливается и освобождает аудио. Существующая локальная репетиция Stage 3 не читается и не перезаписывается Snake.

`tools/build-demo.py` продолжает собирать резервный Stage 3 и исключает ссылку на Snake из его автономной сборки. Новая страница запускается непосредственно из корня репозитория.

## Проверки

Выполнены локально в Chrome с реальным Tone.js и WAV. Звук проверен измерением PCM, а не только состоянием кнопок.

| Критерий | Проверка |
| --- | --- |
| CONNECT / DISCONNECT | Тихое открытие; запуск; остановка; повтор с первого шага; Escape; отмена CONNECT во время загрузки |
| Четыре высоты | Порядок атак реального синтезатора; измерение основных частот G4, B♭4, C5, E♭5 в PCM |
| Восемь шагов | Сканер 0…7 → 0; интервалы 60/104 с; модель проходит 17 шагов и игнорирует дубли callback |
| Добавление, замена, удаление | Все четыре строки melody, пауза, независимые rhythm events и три сигнала в одном столбце |
| Правки во время игры | Реальная замена атаки в Tone lookahead; один запуск транспорта; PCM замены совпадает с одной новой атакой |
| Два голоса | Мелодия и три rhythm events одновременно; затухание до тишины |
| Mute / Unmute | Ритм убирается, мелодия остаётся; отдельная PCM-проверка независимости шин |
| Нет зависших звуков | Конечные gates; отменённые synth/sample атаки дают тишину; DISCONNECT очищает scheduler и пулы |
| Совместимость Stage 3 | Переходы в Songbook и из звучащего Preview; исходные файлы и композиция сохранены; существующие unit- и аудиотесты |

Результаты: `tests/snake.test.cjs` — пройден; `tests/snake-browser.test.cjs` — 34 проверки пройдены; `tests/snake-audio.html` — 18 PCM-проверок пройдены; исходный `tests/audio.html` — 21 проверка пройдена. Существующие `tests/loops.test.js`, `tests/composition.test.cjs`, `tests/roll.test.cjs` — 94 проверки пройдены. В целевом браузерном сценарии нет ошибок JavaScript или HTTP-ресурсов, нет горизонтального переполнения на ширине 390 и 1100 px.

Повторный запуск (при работающем сервере; Playwright требуется только тестовому окружению):

```sh
node tests/snake.test.cjs
PROTOTYPE_URL=http://127.0.0.1:8771 node tests/snake-browser.test.cjs
```

Если Playwright установлен вне проекта, существующие тесты поддерживают `PLAYWRIGHT_MODULE=/absolute/path/to/playwright`. Аудиопроверки также доступны вручную на `/tests/snake-audio.html` и `/tests/audio.html`.

Резервная demo-сборка дополнительно проверена в изолированной временной папке: собирается успешно, не содержит ссылку на отсутствующую страницу Snake и сохраняет все HTML-зависимости. Существующий `tests/browser.test.cjs` завершился успешно: 58 проверок, включая запись, восстановление, mute, остановку реального аудио и очистку ресурсов. В этом старом тесте ожидание такта исправлено с константы 2.5 с (96 BPM) на `4 * 60 / bpm`, поскольку фундамент уже использует 104 BPM.

## Ограничения Stage 01

- Рисунки Snake не сохраняются после обновления страницы; экспорта и undo пока нет.
- Длина цикла, темп и длительность мелодических нот фиксированы. SIGNAL и тембры взяты из основы, финальный саунд-дизайн не выполнялся.
- Вход в окно последних 5 мс перед атакой может отложить правку этого шага на следующий круг.
- Изоляция относится к переходу режимов в одной вкладке. Несколько независимо открытых вкладок не синхронизируются между собой.
- Браузерные и PCM-проверки проведены в Chrome; физические мобильные устройства и другие браузеры не проверялись.
- Nokia/Figma UI, семь интерактивных сцен и следующие этапы не реализованы.

Commit, push и публикация не выполнялись. Старый репозиторий RINGTONE MACHINE не изменялся.
