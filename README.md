## Промпт-дизайн и использование ИИ

При разработке RINGTONE MACHINE я использовал ИИ для поиска решений, проектирования интерфейса и реализации музыкального инструмента.

| Инструмент | Задача | Уровень |
|---|---|---|
| ChatGPT | Концепция и механика SIGNAL SNAKE | 1 |
| ChatGPT, Figma AI | Визуальное направление, макеты и их доработка | 1–2 |
| ChatGPT | Музыкальный сценарий и промпты | 2 |
| Codex | Код синтезатора, звук и интерактивность | 3 |

**Примеры запросов**

- **Концепция:** придумать музыкальный инструмент без традиционной клавиатуры.
- **Интерфейс:** разработать UI в эстетике кнопочной Nokia и Snake.
- **Разработка:** реализовать два голоса, семь музыкальных сцен и управление звуком в реальном времени.

**Моя роль**

Я выбирал концепцию, определял механику взаимодействия, формулировал задачи и ограничения, оценивал результаты и вносил правки. ИИ помогал реализовывать и проверять решения.

**Вывод**

Не все предложенные решения подходили с первого раза. В процессе работы я научился точнее формулировать запросы, находить проблемы в результатах и последовательно улучшать проект.
