# SIGNAL SNAKE · NO ANSWER

Браузерный музыкальный инструмент в корпусе Nokia: история попытки дозвониться, рассказанная мелодией, цифровыми сигналами и помехами. Два независимых голоса, восемь шагов, 104 BPM. Музыку собирает и исполняет пользователь; звук включается после действия на странице.

[GitHub Pages — адрес первой публикации](https://matveyabramov.github.io/signal-snake/) · [Figma — утверждённый дизайн](https://www.figma.com/design/sh7q3C0ABcDxyzGpPaqRRu?node-id=75-1334)

## Управление

| Элемент | Действие |
| --- | --- |
| СОЕДИНИТЬ / CONNECT | Запуск текущей мелодии. При первом открытии ритм пуст, ВЫСОТА = 0, ПОМЕХИ = 0%. |
| ЗАВЕРШИТЬ / Escape | Остановка звука. Рисунки сохраняются в памяти до перезагрузки. |
| МЕЛОДИЯ · Voice A | Сетка 4×8: Eb5, C5, Bb4, G4. Одна нота на шаг; повторный клик убирает её. |
| РИТМ · Voice B | Сетка 3×8: CALL, PING, CLICK. Несколько сигналов на шаг; изменения вступают с начала следующего полного цикла. |
| Значок динамика в LCD | Заглушить / вернуть ритм; виден в режиме РИТМ. |
| OK / PING | Один ручной PING поверх музыки. |
| ВЫСОТА / стрелки ↑↓ телефона | Сдвиг мелодии на −2…+2 ступени до-минорной пентатоники. |
| ПОМЕХИ / СИГНАЛ | Обработка 0–100%; кнопка СИГНАЛ меняет уровень шагами по 25%. Пять полосок связи убывают до нуля. |
| Сцены / стрелки ←→ телефона | Выбор сцены. Во время игры переход с начала следующего цикла; при остановленном звуке выбор запускает сцену. |

Голоса продолжают звучать вместе при переключении сетки. Переход сцены загружает её исходную мелодию, очищает ритм и сбрасывает высоту, помехи и mute. Целевые ритмы и исполнительские подсказки не запускаются автоматически. Цифровая клавиатура и батарейка декоративные. NOISE отсутствует.

## Семь сцен NO ANSWER

1. **ПОИСК СИГНАЛА**
2. **ПЕРВЫЙ КОНТАКТ**
3. **РИТМ**
4. **ПОМЕХИ**
5. **ПОТЕРЯ СВЯЗИ**
6. **ПОВТОРНЫЙ ВЫЗОВ**
7. **ПОСЛЕДНИЙ ЗВОНОК**

Рекомендуемая форма — 26 циклов, 52 такта, около двух минут. Панель УПРАВЛЕНИЕ показывает действие текущего цикла. Исполнитель вручную редактирует сетки, отправляет PING и выбирает следующую сцену.

## Технологии и локальный запуск

HTML, CSS, обычный JavaScript, Web Audio API и локальный Tone.js 15.1.22. Локальные WAV, SVG, Pixel Ultima Bold, IBM Plex Mono и Onest. Для сборки нужен только Python 3; установка npm-пакетов не требуется.

Из корня репозитория:

```sh
python3 tools/build-public.py --output dist
python3 -m http.server 8772 --bind 127.0.0.1 --directory dist
```

Открыть [production-сборку локально](http://127.0.0.1:8772/). Сборку можно повторять; при неизвестных файлах в папке назначения сборщик остановится, чтобы не удалить чужие данные. `python3 tools/build-public.py --check` проверяет состав без записи. Открывать HTML через `file://` не следует.

Для разработки можно обслуживать корень проекта и открывать `snake.html`. Корневой `index.html` и `build/demo/` — архив прежнего инструмента; в релиз они не входят. Публикуется только `dist/`: без внутренних карт, документации, тестов, диагностических страниц, MP3, MIDI и PDF. Сборщик встраивает необходимые данные семи сцен в JS; эти данные доступны посетителю вместе с кодом инструмента.

## Первая публикация

Workflow [Publish SIGNAL SNAKE](.github/workflows/pages.yml) запускается **только вручную** через `workflow_dispatch`, только для `main`. Push и pull request ничего не публикуют. `dist/` генерируется заново в Actions и не хранится в Git.

1. Проверить тариф: репозиторий `matveyabramov/signal-snake` приватный и принадлежит личному аккаунту. Для Pages из него нужен **GitHub Pro**. На GitHub Free Pages работает только с публичным репозиторием. При проверке Settings → Pages 30 октября 2026 года GitHub показал «Upgrade or make this repository public to enable Pages»: публикация из текущего приватного репозитория заблокирована тарифом. Нужно подключить GitHub Pro либо отдельно разрешить перевод репозитория в public (при этом станут доступны и внутренние материалы репозитория). [Ограничения GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
2. После разрешения владельца выполнить финальный commit и push в `main`, включая `.github/workflows/pages.yml`, сборщик, исходники и лицензии.
3. В **Settings → Pages → Build and deployment → Source** выбрать **GitHub Actions**. Репозиторий может остаться приватным при подходящем тарифе; опубликованный сайт будет публичным. Если для environment `github-pages` действует подтверждение deployment, одобрить его при запуске.
4. В **Actions → Publish SIGNAL SNAKE → Run workflow** выбрать `main` и запустить вручную.
5. После успешного deploy открыть [SIGNAL SNAKE](https://matveyabramov.github.io/signal-snake/) и выполнить короткую проверку CONNECT / ЗАВЕРШИТЬ.

Настройки Pages, видимость репозитория, commit, push и deploy в ходе подготовки релиза не изменялись.
