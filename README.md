# Stage 3.1 · Editable Piano Roll

Запиши фразу **R → игра → R**, затем нажми **EDIT** в панели Piano Roll. Пустая клетка добавляет событие; перетаскивание меняет время и высоту, правый край — удержание. **⌫** удаляет выбранный блок, **⌘Z** отменяет. **Слушать / Space** запускает оба лупа. **PERFORM** защищает сетку от случайных правок. Voice B имеет отдельные четыре строки без растягивания one-shot.

Открой локальный инструмент и нажми **Учиться → Начать**. Четыре урока: мелодия A D F D, ритм C X C X, реальные команды управления и репетиция NO ANSWER на ориентировочные 2:40. # RINGTONE MACHINE — Stage 2.2

**Нажми R → сыграй → нажми R ещё раз. Quantization = OFF по умолчанию.** Первая запись запускает транспорт сама. Отсчёта нет. Можно закончить фразу, не дожидаясь четырёх тактов.

Простой браузерный инструмент на HTML/CSS/JavaScript с локальным Tone.js 15.1.22. При первом открытии дорожки пусты; готовых музыкальных партий нет. Сохранившуюся собственную репетицию можно явно вернуть через Restore — музыка сама не включается.

## Запуск

Из этой папки:

```sh
python3 -m http.server 8767 --bind 127.0.0.1
```

Открой [http://127.0.0.1:8767](http://127.0.0.1:8767). При первом запуске «Понятно, закрыть» в короткой инструкции подготавливает звук. Если сразу начать через R, все нажатия уже сохраняются; играть со звуковым откликом можно после окончания надписи о включении аудио. Для самого инструмента установка зависимостей и сборка не нужны. Все WAV, Tone.js и шрифт находятся локально.

## Первая композиция без подготовки

1. **R.** На экране сразу появится RECORDING, а большая кнопка станет FINISH. Если открыта стартовая подсказка, R также закрывает её и начинает запись.
2. Сыграй мелодию клавишами **A S D F G H J K L**. Любые из этих нот сочетаются; можно удерживать ноты и играть небольшие аккорды. Достаточно фразы на 2–4 секунды.
3. **R ещё раз.** Фраза немедленно сохранится. QUEUED означает: луп уже готов, повтор начнётся с ближайшего такта. Это ожидание обычно короче 2.5 секунды.
4. Теперь выделен пустой **Loop 2**. Сразу нажми **R**, не ожидая первого повтора. Сыграй несколько сигналов клавишами **Z X C V**, затем снова нажми R.
5. Обе фразы повторяются. Играй новую мелодию поверх них: без активной записи она не добавится в луп.
6. **]** усиливает SIGNAL, **[** возвращает чистый звук. **Q / W** убирают и возвращают первый и второй слой.
7. Заверши музыку: убери слои, сыграй и отпусти последнюю ноту, нажми **Esc**. Готовые лупы сохранятся. Space запустит их вместе с начала.

**HOW TO PLAY / I** всегда открывает короткую инструкцию внутри инструмента. Читать этот файл для начала игры не обязательно.

## Клавиши

| Действие | Клавиши |
| --- | --- |
| C4, E♭4, F4, G4, B♭4, C5, E♭5, F5, G5 | A S D F G H J K L |
| CALL / PING / CLICK / NOISE | Z / X / C / V |
| Выбрать Loop 1 / Loop 2 | 1 / 2 |
| Начать / закончить запись | R |
| Отменить текущий дубль, сохранить прежнюю фразу | T |
| Mute / Unmute первого и второго лупа | Q / W |
| Mute выбранного лупа | M |
| Очистить выбранный луп | ⌫ дважды за 3 секунды |
| Транспорт: старт / стоп | Space |
| Немедленно остановить звук и отменить незаконченный дубль | Esc |
| SIGNAL −5% / +5% | [ / ] |
| HOW TO PLAY | I |

Раскладка определяется по физическим клавишам и работает с русским языком ввода. Удерживание R не вызывает многократные переключения. Command/Control/Option-сочетания не перехватываются. В выпадающем списке музыкальные клавиши не срабатывают; после выбора фокус возвращается к REC. При фокусе на SIGNAL можно продолжать играть и пользоваться R.

Все основные действия доступны мышью и с клавиатуры. Ноты/пэды также поддерживают указатель и мультитач. Кнопки имеют подсказки при наведении; Tab/Enter позволяют активировать их с клавиатуры.

## Длина и ритм

Темп фиксирован: **96 BPM, 4/4**.

- **Auto:** выбирается минимальная длина из **1 / 2 / 4 тактов**, которая вмещает сыгранную фразу с окончанием последней ноты. Один такт — 2.5 s, два — 5 s, четыре — 10 s.
- Пауза после последней отпущенной ноты не увеличивает длину Auto. Начальная пауза от R до первой ноты входит в фразу.
- Если нота ещё удерживается при FINISH, её записанное окончание ставится в момент FINISH. Живая нота продолжает звучать до отпускания клавиши.
- Можно заранее выбрать **1 / 2 / 4 bars** вручную. Тогда раннее FINISH сохраняет именно эту длину, дополняя остаток тишиной.
- В ручном режиме запись сама завершится на выбранной длине. В Auto максимальное окно — четыре такта; по его окончании дубль также завершится сам. Ждать этой границы не требуется.
- **OFF включён по умолчанию:** ни начала, ни положительные длительности не округляются. Дополнительно доступны **1/4 / 1/8 / 1/16** по явному выбору; к ней округляются только начала нот. Фактическая длительность удержания сохраняется без округления; note-off рассчитывается относительно сдвинутого начала. Во время дубля настройки заблокированы.
- Повторы начинаются на общей границе такта и имеют только музыкальные длины 1/2/4. Лупы разной длины остаются синхронными.

В QUEUED события уже сохранены и дорожку можно сменить. Если ближайшая граница уже слишком близка для безопасного планирования звука, выбирается следующая. Во время записи выбранная дорожка закреплена; R заканчивает именно её. Автоматический переход на пустую дорожку никогда сам не начинает следующий дубль.

## Замена, отмена и очистка

- Выбери заполненный Loop 1 или 2: большая кнопка покажет **RE-RECORD**. Нажми R, сыграй новую фразу и нажми R ещё раз. Старый луп заменится полностью.
- Во время нового дубля прежняя фраза этой дорожки не звучит. **T / Cancel recording** отбрасывает только дубль и возвращает прежний луп. Второй R всегда означает FINISH, а не отмену.
- Пустой дубль не стирает прежнюю фразу и не создаёт пустого автоматического слоя.
- **Clear selected / ⌫:** первое нажатие только показывает вопрос, второе в течение трёх секунд удаляет выбранный луп. Смена дорожки отменяет подготовку удаления.
- Mute влияет только на записанный слой; ручной голос остаётся доступен. Unmute возвращает будущие события на текущей позиции, не воспроизводит пропущенные ноты.
- Stop отменяет незавершённый дубль, отпускает звук и сохраняет готовые фразы. После Start оба лупа начинаются вместе с начала, каждый со своей длиной.

## Репетиции

Готовые события, длины, mute, сетка, режим длины, выбранная дорожка и SIGNAL сохраняются в **localStorage** с версией формата 3 (форматы 1 и 2 также читаются). Аудиозапись не создаётся; незавершённый дубль не сохраняется.

- При открытии ничего не загружается в дорожки и не звучит автоматически.
- **Restore:** явно вернуть свою репетицию. Затем **Space** — послушать, **R** — перезаписать выбранный слой. Во время игры Restore недоступен; сначала Esc.
- **Start Fresh:** начать с пустых дорожек. Если текущие дорожки заполнены, потребуется второе нажатие за три секунды. При пустом экране действие сразу удаляет предложенную сохранённую репетицию.
- Можно игнорировать Restore и записать всё заново: первый законченный новый дубль заменит сохранённую сессию.
- Если браузер запретил localStorage, инструмент продолжит работать в памяти и сообщит, что после обновления записи исчезнут.

Сохранение относится к текущему браузеру **и адресу с портом**. Например, сохранение на `127.0.0.1:8767` отличается от `localhost:8767` или другого порта. Очистка данных сайта/приватный режим могут удалить репетицию.

## Ограничения

Одна запись за раз, один мелодический и один сигнальный слой. Перезапись заменяет луп целиком: overdub, undo, редактор событий и экспорт не добавлены. Длительность удержания сохраняется и может переходить через границу повтора. FINISH или лимит записи закрывает ещё удерживаемую записанную ноту с явным сообщением; ручная нота звучит до отпускания. До 512 событий в дубле и 32 одновременных записанных мелодических голосов. Ограничения больших физических аккордов зависят от клавиатуры MacBook.

Скрытие вкладки останавливает транспорт; потеря фокуса отпускает ручные ноты. Проверки проведены в Chrome на macOS; Safari/Firefox отдельно не валидированы. Финальный Y2K-дизайн в этот этап не входит.

## Stage 2.2: предсказуемая запись

Нажатия и отпускания захватываются сразу, до загрузки звука, от одного нуля R на монотонных часах. Ритм не зависит от момента старта Transport. В OFF хранятся точные дробные позиции и удержания. Playback назначает каждую ноту по точному времени внутри окна, а не требует совпадения с точкой 1/16. После Finish оба лупа синхронизируются по общим тактам.

Таймлайн показывает отдельный блок для каждой сохранённой ноты/пэда, включая C4, повторения и аккорды. **8 NOTES** означает восемь сохранённых нот. Хвост за краем лупа отображается переносом, не создавая дополнительного события. Auto считает всю фразу; превышение поддерживаемого окна 10 секунд явно показано и закрывает дубль.

Проверка за 30 секунд: Start Fresh → OFF/Auto → R → **A A D F | G F D A** примерно по одной ноте на долю → R. Ожидаются **2 BARS / 8 NOTES**, восемь видимых блоков и повтор с твоими интервалами. Затем R → Z X C V → R, импровизация, Q/W и SIGNAL, завершение Esc.

Старые записи уже могли потерять timing при прежнем квантовании или загрузке аудио. Restore сохраняет их совместимость, но восстановить отсутствующие события невозможно: для проверки новой версии сыграй фразу заново. CALL остаётся исправленным одноатакным 800 ms сэмплом; остальные WAV и `audio.js` не изменены.

Полный аудит timing pipeline: [Stage 2.2](docs/STAGE-2.2.md). Отдельные доказательства восьми нот: [Scenario A](docs/SCENARIO-A.md).

```sh
node tests/loops.test.js

node tests/durations.test.js
```

Реальные аудиорендеры: [tests/audio.html](http://127.0.0.1:8767/tests/audio.html), кнопка Run audio checks. Используется тот же production audio graph, локальные WAV и Tone.Offline.

Браузерные сценарии требуют отдельно доступного Playwright с Chrome; игровая страница этой зависимости не использует:

```sh
node tests/fidelity-browser.test.cjs
node tests/browser.test.cjs
node tests/edges.test.cjs
```

Путь к нестандартно установленному Playwright задаётся через `PLAYWRIGHT_MODULE`, адрес — через `PROTOTYPE_URL`, папка результатов — через `RESULT_DIR`. Аудиопроверки также доступны на `tests/duration-call-audio.html`. Проверки содержат изолированные тестовые нажатия; приложение их не загружает.
